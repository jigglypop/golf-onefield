무엇을 계산하나

공 표면 응력장 하나에서 항력과 양력이 같은 크기로, 45° 대칭으로 투영된다고 둡니다. 스핀축 기울기 a는 축으로 펼치지 않고 대칭을 살린 모드로 전개해서, 계수 8개를 담은 3차원 장 하나(1.6 MB)를 읽습니다.

k = (v_ev·|u| + h·w) / √2 du/dt = −k·u + k·(ω̂ × u) − ŷ x = c0 + c2·s² + c4·s⁴ + c6·s⁶ z = s·(c1 + c3·s² + c5·s⁴ + c7·s⁶) s = sin a

v_ev = 0.3881, h = 0.2714 (투어 아이언 평균으로 동결). 단위는 무차원이며 공기밀도 1.2 kg/m³에서 1 = 58.54 yd입니다.
