# 변수: u = |u| (무차원 속도, 1 = 22.9 m/s), w = 무차원 스핀 (R ω / 22.9 m/s), S = w/u (스핀 비), Re = 레이놀즈 수
# kd = |u| C_D,  kl = |u| C_L.  함수: sqrt exp ln abs tanh atan min max pow, 연산 + - * / ^
# 매개변수 줄: "이름 = 시작 하한 상한" (맞춤) 또는 "이름 = 값" (고정). 이름이 beta 면 스핀 감쇠 dw/dt = -beta w u.
# 훈련은 PGA 12행의 캐리·최고 높이·착지각, 판정은 LPGA 11행 세 양과 USGA 20행 분포 평균 캐리.

kl = c*w*u/sqrt(u^2 + (l*w)^2)
